# Экспортируйте черновик плейлиста

> Для кого: Для тех, кто собрал временный сет и хочет получить файл вне приложения.
> Задача: Экспортировать M3U или CSV и понимать, что именно записывается.
> Тип: Руководство

## Прямой API

Вызовите `POST /api/export` и передайте `name`, `track_ids`, `output_dir` и `format`. Формат должен
быть `m3u` или `csv`; ответ вернёт созданный `path`. Прямой клиент указывает ID треков явно. Браузер
делает то же самое, когда отправляет временный текущий сет. См.
[справочник API](../reference/api.md).

Текущий сет остаётся временным до экспорта. Строки фонотеки и результаты поиска изменяют его только
после явного добавления треков.

## Действия в интерфейсе

Блок **Сет и экспорт** по умолчанию свёрнут, чтобы оставить больше места по высоте для кандидатов.
Добавление трека обновляет видимый счётчик сета, но не раскрывает блок. Разверните его, когда хотите
просмотреть временный сет. В открытом блоке выводится по 20 треков на страницу с кнопками **Prev**
и **Next**, а текущая страница прокручивается внутри блока.

1. Добавьте треки в текущий сет из фонотеки, результатов поиска или другой области интерфейса.
2. Разверните **Сет и экспорт**.
3. Укажите название плейлиста.
4. Выберите или введите выходную папку.
5. Нажмите кнопку экспорта M3U или CSV.

Если выходной папки нет, приложение создаст её.

## Имена файлов

Экспортёр преобразует название плейлиста в безопасное имя: сохраняет буквы, цифры, `.`, `_` и `-`,
заменяет остальные последовательности символов на `_`, а если после очистки имя пусто — использует
`playlist`.

## Формат M3U

Файл M3U содержит:

- строку `#EXTM3U`;
- по одной строке `#EXTINF:-1,Artist - Title` для каждого трека с исполнителем и названием;
- сохранённый локальный путь к каждому треку.

## Формат CSV

Файл CSV содержит столбцы:

```text
artist,title,bpm,key,energy,path
```

## Сохранение в коллекцию Rhythm Lab

Текущий сет также можно сохранить как коллекцию Rhythm Lab. Каждый элемент содержит
`catalog_uuid`, `track_uuid` и `content_generation`. Эта операция записывает данные в базу меток
Rhythm Lab, а не исходные аудиофайлы.

## Приватность

Экспорт содержит локальные пути и может раскрывать структуру коллекции. Считайте M3U и CSV личными
файлами, если вы намеренно не удалили из них приватные сведения.
