# Workflows

Use workflows when you know the outcome you want but do not yet know which model or screen can
produce it.

## Choose an outcome

| Outcome | Workflow |
| --- | --- |
| A short list around one reference track | [Find compatible tracks](./find-compatible-tracks.md) |
| A broader pool to audition later | [Build crates](./build-crates.md) |
| A reusable score for your own recurring concept | [Train a personal classifier](./train-personal-classifier.md) |
| Fresh SONARA data after an analysis change | [Reanalyze SONARA data](./reanalyze-sonara-split-storage.md) |
| A safe routine for keeping the catalog current | [Maintain library](./maintain-library.md) |

Each result is still material for review. The app narrows and organizes the collection, and
listening decides what survives.

## Pages

- [Find compatible tracks](./find-compatible-tracks.md): one reference track to candidate list.
- [Build crates](./build-crates.md): create listening pools and export them.
- [Train a personal classifier](./train-personal-classifier.md): turn Rhythm Lab labels into a promoted score.
- [Reanalyze SONARA data](./reanalyze-sonara-split-storage.md): back up the library and reanalyze only when chosen.
- [Maintain library](./maintain-library.md): the repeatable routine for tags, validation, duplicates, and repair.

## Working habit

Work in previews first. Export or apply only after listening or reviewing reports.

The browser UI is Russian. Control names in these workflows are given as the Russian string with the
English meaning in parentheses, and [UI language](../help/ui-language.md) carries the full mapping.
