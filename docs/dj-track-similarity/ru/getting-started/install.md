# Установка для локального анализа

> Для кого: Для тех, кто готовит проект к сканированию, работе в интерфейсе и необязательному анализу.
> Задача: Установить только нужные компоненты и понимать требования каждого инструмента.
> Тип: Учебная инструкция

Проект состоит из пакета Python с дополнительными наборами зависимостей, интерфейса React и
документации VitePress. В примерах предполагается, что окружение уже активировано.

## Требования

- Python `>=3.10`.
- FFmpeg в `PATH` либо полный путь к исполняемому файлу в `DJ_TRACK_SIMILARITY_FFMPEG`.
- Node.js и npm для сборки `frontend/dist` или сайта документации.
- Локальная папка с аудио. Для обычной работы облачное хранилище не требуется.

При запуске сервер вызывает `require_ffmpeg()`. Если FFmpeg не найден, сервер останавливается с
понятным сообщением об установке, а не переходит незаметно на неполное декодирование.

## Создайте и активируйте окружение

Пример для PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

После активации используйте в командах обычные `python` и `dj-sim`.

## Базовый пакет

```powershell
python -m pip install -e ".[dev]"
```

Базовый пакет устанавливает основные зависимости: NumPy, Mutagen, Pydantic, Typer, FastAPI,
Uvicorn, Joblib и инструменты тестирования. Этого достаточно для сканирования, CLI, серверного API,
экспорта и выбора базы. Клиент React собирается отдельно.

## Дополнительные компоненты

Устанавливайте только те наборы, которые нужны:

```powershell
python -m pip install -e ".[sonara,ml,dev]"
```

Текущий набор `sonara` устанавливает SONARA `0.3.5`. PyPI публикует wheel-пакеты `cp310-abi3`, в том
числе для Windows x64, поэтому в поддерживаемых окружениях Python 3.10+ не нужно собирать
SONARA локально.

Перед анализом фонотеки проверьте установленную версию среды выполнения:

```powershell
python -c "import sonara; print(sonara.__version__)"
```

В текущем проверенном окружении выводится `0.3.5`. Это фиксирует зависимость, использованную для
текущей сборки. Более новый выпуск SONARA можно принять, одновременно обновив исходный код проекта,
манифесты и lock-файл, а затем выполнив сфокусированные проверки совместимости.

Набор `ml` фиксирует один взаимно совместимый стек загрузчиков. Установленные пакеты должны
предоставлять возможности, контрольные точки и формы результатов, которые используют адаптеры, но
среда выполнения не отклоняет пакет только из-за изменения версии дистрибутива.

- `sonara`: извлечение признаков SONARA.
- `ml`: пакеты для инференса PyTorch, Torchaudio, Torchvision, TorchCodec, nnaudio, Transformers,
  Hugging Face Hub, LAION CLAP, MAEST и MuQ.
- `ann`: необязательный HNSW-бэкенд для постоянных вспомогательных индексов ANN.
- `rhythm-lab`: scikit-learn для обучения классификаторов.

Для необязательной поддержки ANN:

```powershell
python -m pip install -e ".[ann,dev]"
```

Для обучения в Rhythm Lab:

```powershell
python -m pip install -e ".[rhythm-lab,dev]"
```

## Соберите интерфейс

Клиент React использует текущие структуры API. Бэкенд раздаёт `frontend/dist`, если каталог существует.
Создайте сборку:

```powershell
npm --prefix .\frontend install
npm --prefix .\frontend run build
```

После изменений клиента запустите его тесты API:

```powershell
npm --prefix .\frontend test
```

Для разработки интерфейса с автоматическим обновлением:

```powershell
npm --prefix .\frontend run dev
```

Сервер разработки по умолчанию слушает `127.0.0.1`.

## Соберите сайт документации

Бэкенд раздаёт статическую документацию из `docs/dj-track-similarity/site`, если каталог существует.
Установите зависимости, синхронизируйте Vale и запустите проверку со сборкой:

```powershell
npm --prefix .\docs\dj-track-similarity install --no-package-lock
npm --prefix .\docs\dj-track-similarity run vale:sync
npm --prefix .\docs\dj-track-similarity run check
```

`npm run check` выполняет строгую проверку стиля Vale перед сборкой VitePress. Созданный каталог
`site/` исключён из Git.

## Запустите сервер

```powershell
dj-sim serve --host 127.0.0.1 --port 8765 --db .\data\library.sqlite
```

Фиксированные порты по умолчанию:

| Инструмент | Порт | Комментарий |
| --- | ---: | --- |
| Основной бэкенд | `8765` | `dj-sim serve` |
| Сервер разработки Vite | `5173` | `npm run dev` в `frontend/` |
| Rhythm Lab | `8777` | отдельный интерфейс разметки и обучения |

На каждом фиксированном порту запускайте только один экземпляр.
