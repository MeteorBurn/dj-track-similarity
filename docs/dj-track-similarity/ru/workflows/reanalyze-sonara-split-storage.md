# Миграция хранилища SONARA и повторный анализ

> Для кого: Пользователи, принимающие изменения SONARA или структуры базы.
> Задача: Предварительно проверить структурные изменения и создать резервные копии, затем
> перестроить только выбранные результаты анализа.
> Тип: Сценарий

Обычный запуск приложения никогда не мигрирует и не адаптирует несовместимую базу. Он отклоняет
пару Core/Artifacts с понятным сообщением. Миграция и повторный анализ — отдельные явные решения.

## 1. Проверьте комплект

Выбранная фонотека состоит из:

```text
library.sqlite
library.artifacts.sqlite
```

Необязательная база `library.evaluation.sqlite` появляется только тогда, когда она нужна сценарию
оценки. Core и Artifacts обязательны и используют один `catalog_uuid`.

Перед обслуживанием остановите задачи и другие процессы записи. Храните текущие файлы вместе.

## 2. Просмотрите план миграции

Режим предварительной проверки открывает Core, Artifacts и существующую Evaluation только для
чтения. Он сообщает, какие таблицы будут перестроены или исключены и какие семейства анализа могут
потребовать повторного запуска:

```powershell
dj-sim migrate-database --db .\data\library.sqlite --dry-run
```

Проверьте точные пути, структурные изменения, предупреждения и предложенное расположение резервных
копий. Предварительная проверка не создаёт копии, не записывает SQLite и не запускает анализ.

## 3. Применяйте только после проверки

Если вы принимаете план, повторите команду без `--dry-run`:

```powershell
dj-sim migrate-database --db .\data\library.sqlite
```

Введите точное подтверждение:

```text
MIGRATE DATABASE
```

Параметр `--backup-dir` позволяет выбрать другой каталог резервных копий. До замены любой базы
команда создаёт самодостаточные резервные копии Core и Artifacts, совместно проверяет их целостность
и общую идентичность каталога. Финальная проверка исходных файлов подтверждает, что они всё ещё
соответствуют просмотренному плану.

Команда перестраивает пару под исключительными блокировками SQLite и завершает проверками
целостности, внешних ключей и потерянных связей. При контролируемом сбое она восстанавливает
проверенную пару копий. Если процесс завершится между публикацией двух баз, обычный запуск отклонит
пару и укажет записанные пути восстановления и резервных копий.

Evaluation проверяется для предупреждений, но эта миграция её не переписывает.

## 4. Проверьте отчёт

Сохраняйте указанные пути резервных копий Core и Artifacts, пока не проверите мигрированную
фонотеку. Отчёт также перечисляет исключённые устаревшие строки и семейства анализа, которым могут
понадобиться новые результаты.

Миграция не решает, желателен ли повторный анализ. Она не запускает задачи SONARA, ML или
классификаторов.

## 5. При необходимости запустите ограниченный пилот SONARA

Когда мигрированная база открывается нормально, начните со знакомых файлов:

```powershell
dj-sim analyze --models sonara --sonara-outputs core,timeline,embedding,fingerprint --limit 100 --db .\data\library.sqlite
```

Текущая проверенная версия SONARA — `0.3.5`; это описание, а не постоянное ограничение проекта.
Обновляйте SONARA и адаптируйте проект по своему решению, затем запускайте целевые проверки новых
полей и возможностей.

Проверьте ошибки и характерные результаты поиска до решения о продолжении.

## 6. Завершите только выбранные результаты

Убирайте `--limit` только после одобрения запуска для всей фонотеки:

```powershell
dj-sim analyze --models sonara --sonara-outputs core,timeline,embedding,fingerprint --db .\data\library.sqlite
```

`core` включается всегда. Запрашивайте необязательные результаты в соответствии с использующими их
сценариями.

## 7. Переобучите затронутые классификаторы

Если обновление SONARA меняет упорядоченный рецепт признаков классификатора, используйте сохранённые
профили и метки Rhythm Lab, чтобы переобучить и опубликовать только этот классификатор. Затем
выполните:

```powershell
dj-sim analyze-classifiers --db .\data\library.sqlite
```

Расчёт классификаторов читает сохранённые входы и записывает оценки в базу. Он не декодирует и не
изменяет исходное аудио.
