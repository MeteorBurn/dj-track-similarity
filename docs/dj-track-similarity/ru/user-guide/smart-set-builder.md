# Создайте черновик в Smart Set Builder

> Для кого: Для тех, кто готовит упорядоченный список для прослушивания или диджейского сета.
> Задача: Объяснить настройки SET, требования, предварительный просмотр Hybrid и границы безопасности.
> Тип: Руководство

SET помогает после того, как поиск нашёл слишком много подходящих треков, а вам всё ещё нужны
музыкальное направление и порядок проверки. Укажите опорные точки или разрешите приложению выбрать
их, затем задайте желаемую близость, разнообразие, форму энергии и, при необходимости, направление
темпа или классификатора.

Результат — упорядоченный черновик для прослушивания. По нему удобно искать возможный маршрут через
фонотеку и замечать пробелы, повторы или резкие скачки. Это не готовый план выступления, не
генератор cue-меток и не гарантия того, что соседние треки сведутся.

## Вход через браузер и API

Откройте **SET** в браузере. Вложенные вкладки **Set Builder** и **Hybrid Preview** хранят элементы
управления, результаты, ошибки и отмену независимо. Клавиши `ArrowLeft` и `ArrowRight` переходят
между ними, а `Home` и `End` — к первой и последней вкладке.

Set Builder вызывает `POST /api/set-builder/generate`, а Hybrid Preview —
`POST /api/search/hybrid`. Обе формы браузера позволяют выбирать источники и включать
пользовательские веса. Конечные точки только возвращают данные. Экспорт остаётся отдельным действием
через `POST /api/export`. Те же поля и диапазоны описаны в
[справочнике API](../reference/api.md).

## Что происходит при создании

1. SET ограничивает пул треками с необходимым анализом.
2. Находит кандидатов, связанных с опорными точками несколькими аудиопризнаками.
3. Балансирует кандидатов по режиму, разнообразию, энергии, темпу, исполнителям и необязательным настройкам классификаторов.
4. Возвращает упорядоченный черновик со сведениями о покрытии.
5. До нажатия **Add preview** текущий сет не изменяется.

Вкладка **SET** создаёт черновик через `/api/set-builder/generate`.

## Требования

SET всегда требует широкий анализ SONARA. Кроме него, треку нужны все включённые источники
эмбеддингов. По умолчанию включены:

- эмбеддинга MERT;
- эмбеддинга MAEST;
- эмбеддинга MuQ;
- аудиоэмбеддинга CLAP.

Исходные веса по умолчанию:

| Сигнал | Исходный вес |
| --- | ---: |
| `mert` | `0.30` |
| `maest` | `0.18` |
| `muq` | `0.15` |
| `clap` | `0.22` |
| `sonara_broad` | `0.30` |

SET нормализует их по включённым эмбеддингам вместе с широким сигналом SONARA. При полном наборе
каждый исходный вес делится на `1.15`, а итог возвращается в `weights_used`.

Чтобы точно воспроизвести профиль запроса до добавления MuQ, отключите MuQ и включите
пользовательские веса. Браузер отправит только `mert`, `maest` и `clap` с исходными весами `0.30`,
`0.18`, `0.22`, а также `sonara_broad` с весом `0.30`. Тогда MuQ не загружается и не требуется для
участия. Перед расчётом backend нормализует эти исходные значения. Пользовательские веса должны
содержать ровно ключи включённых эмбеддингов плюс `sonara_broad`.

Ответ содержит общее и подходящее количество треков, а также число отсутствующих результатов MERT,
MAEST, MuQ, CLAP и SONARA.

## Источник референсных треков

**Manual - selected** использует выбранные референсные треки (seed) как промежуточные опорные точки. Бэкенд проверяет полноту их
признаков и применяет ограничение по исполнителю: не более одного трека известного исполнителя в одном
черновике.

**Auto - random start** выбирает первую опорную точку из фонотеки с полными признаками, а затем подбирает
связанные промежуточные опорные точки. Значение **Auto anchors** ограничивается диапазоном `1..5`.

## Режим сета

- **Similar crate - close** остаётся близко к опорным точкам и реже рискует разнообразием.
- **Weird adjacent - odd** допускает менее очевидный соседний материал, сохраняя связь с опорными точками.
- **Balanced set - flow** балансирует сходство, разнообразие, совместимость перехода, кривую энергии и ограничения исполнителей.
- **Discovery - wide** расширяет поиск ради новизны, но сохраняет связь кандидатов с опорными точками.

Выбирайте режим по тому, что хотите услышать. Close полезен для цельной подборки, Balanced — хороший
первый черновик, а более широкие режимы находят неочевидные связи, которым требуется внимательная
проверка на слух.

## Размер и разнообразие

- **Track limit** принимает `1..500`. Референсные треки и опорные точки входят в этот лимит.
- **Diversity** принимает `0.00..1.00`. Малое значение держит результат ближе к опорным точкам, большое сильнее разносит кандидатов, сохраняя связь.

## Кривая энергии

- **Balanced** удерживает энергию рядом с контекстом опорных точек.
- **Warmup** начинает ниже и постепенно поднимается.
- **Peak** предпочитает высокую энергию и плотность.
- **Wave** создаёт чередование подъёма и спада.

## Настройки BPM

Режим **General BPM** по умолчанию использует BPM и тональность только как дополнительные данные о
совместимости перехода. Сначала SET берёт актуальные данные темпа SONARA с корректной сигнатурой. При уверенности
ниже `0.45` он проверяет варианты темпа SONARA и тег BPM из Mutagen. `grid_stability` может ослабить
надёжность темпа; при низкой надёжности оценка движется к нейтральной, а не превращается в бонус
сходства или жёсткое исключение.

Для тональных переходов SET сначала предпочитает корректный тег Camelot, затем результат Camelot
SONARA, а после этого преобразует обычное имя тональности. Одинаковые, параллельные и соседние
тональности получают градуированную совместимость, а не проверку простого совпадения строк. Низкая
уверенность SONARA приближает гармоническую оценку к нейтральной и не превращает совпадение двух
сомнительных значений в сходство само по себе.

Явные режимы траектории:

- **Low to high**: движение от меньшего BPM к большему.
- **High to low**: движение от большего BPM к меньшему.

При активной траектории:

- **BPM change** может быть slow, medium или fast;
- **Start BPM** и **Target BPM** принимают `20..300` либо остаются пустыми для автоматического выбора;
- половинный и двойной темп учитываются для совместимости перехода, но не заменяют фактическую траекторию BPM.

## Ползунки классификаторов

Опубликованные классификаторы могут добавлять предпочтение SET:

- **Preference** находится в диапазоне от `-1.00` до `1.00`;
- **Flow** может быть flat, rise или fall.

SET использует то же состояние доступности классификаторов, что и CLASS. Недоступный профиль
остаётся в списке со статусом и причиной блокировки, но не показывает элементы **Preference** и
**Flow**, а его значения не попадают в запрос SET. Доступный профиль показывает счётчики готовности
и оба элемента управления.

Отсутствующая оценка классификатора остаётся нейтральной. Эти элементы читают сохранённые баллы, но
не обучают модель и не декодируют аудио.

## Предварительный просмотр Hybrid

Во вкладке SET находится **Hybrid preview** — явный взвешенный просмотр по сохранённым данным MERT,
MAEST, MuQ, SONARA и CLAP. По умолчанию бэкенд включает `mert`, `maest`, `muq`, `sonara` и `clap`
с одинаковым весом `0.20`. В браузере доступны флажки всех источников, **Custom weights** и действия
сброса. Чтобы воспроизвести профиль Hybrid до MuQ, отключите MuQ: отключённые источники не попадают
в запрос и не остаются скрытым требованием готовности.

Hybrid:

- требует от одного до пяти выбранных референсных треков;
- позволяет включать и отключать каждый источник;
- принимает веса источников от `0.00` до `1.00`;
- запрашивает `1..100` кандидатов на источник;
- показывает до `1..100` строк;
- применяет необязательный штраф риска перехода от `0.00` до `1.00`;
- использует предпочтения и риск классификаторов, если опубликованные модели предоставляют совместимые сигналы.

Риск перехода v2 может использовать сохранённую устойчивость сетки ритмических долей и структурные границы
SONARA. Это по-прежнему диагностика для порядка, проверяемого на слух: не cue-метки и не обещание
удачного сведения. Версия v1 сохраняет первоначальный расчёт для воспроизводимых оценок.

Последовательность SET использует структуру отдельно от компонентов риска Hybrid. При наличии
структурных данных уверенность перехода сочетает `50%` темпа, `30%` гармонической совместимости и
`20%` структуры. Без структуры используются `60%` темпа и `40%` гармонической совместимости.
Устойчивость сетки ритмических долей влияет через надёжность темпа.

Точные правила темпа, Camelot и структуры см. в
[контракте SONARA v0.3.1](../reference/sonara-v0-3-1-contract.md).

Интерфейс записывает сессии и события оценки для обратной связи. Сам черновик не изменяет треки и
текущий сет.

## Добавьте черновик

Нажмите **Add preview**, чтобы добавить треки текущего черновика SET в текущий сет. Действие
доступно только для последнего ответа Set Builder, у которого всё ещё совпадают база и состояние
формы. Оно никогда не добавляет результаты Hybrid или другой вкладки поиска. Уже добавленные треки
не дублируются. Экспорт остаётся отдельным шагом.
