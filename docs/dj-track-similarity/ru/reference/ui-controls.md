# Справочник по элементам браузерного интерфейса

> Для кого: Для тех, кому нужны актуальные диапазоны и значения по умолчанию в браузере.
> Задача: Описать текущий интерфейс, который работает с backend API.
> Тип: Справочник

Браузер работает с единым комплектом каталога. В окне выбора базы указывается файл Core;
исполняемая часть находит обязательный соседний `*.artifacts.sqlite` и проверяет общий
`catalog_uuid`. Необязательный `*.evaluation.sqlite` открывается только в сценариях оценки.
Отдельных элементов для выбора баз Timeline или Representations нет.

## База данных и фонотека

- **Выбрать базу** выбирает или создаёт файл Core. Структурно несовместимый или неполный каталог
  отклоняется и не мигрирует на месте.
- **Music root** и **Scan workers** задают сканирование. Сканирование и **Refresh Tags** обновляют
  строки каталога, не перезаписывая исходное аудио.
- Страница фонотеки содержит до `200` треков. **Prev**, **Next** и поле номера страницы запрашивают
  по одной странице `/api/tracks`.
- Все строки текущей страницы отображаются в одном прокручиваемом списке. Второй пагинации по окнам
  строк нет.
- Текстовый поиск по фонотеке работает в режимах **LIKE** и **FTS**. Пресеты, фильтр понравившихся
  треков, оценки классификаторов и сортировка тоже передаются backend.
- Прослушивание идёт через `/media/{track_id}`. Подробные метаданные загружаются по требованию из
  `/api/tracks/{track_id}`. Запись отметки «нравится» содержит `catalog_uuid`, `track_uuid` и
  `expected_content_generation`.

При смене базы старые запросы фонотеки и поиска отменяются или становятся недействительными. Строки
треков объединяются по `catalog_uuid` и `track_uuid`; если ответы пришли одновременно, побеждает
наибольший `content_generation`.

## Анализ

Начальные значения анализа:

| Элемент | По умолчанию | Диапазон или смысл |
| --- | ---: | --- |
| **Analyze limit** | `0` | `0..100000`; `0` означает всю подходящую фонотеку |
| **Scan workers** | `8` | Ограничивается локальным пределом рабочих потоков |
| **Track batch** | `8` | `1..64` |
| **Inference batch** | `16` | `1..128` |
| **SONARA batch** | `8` | `1..16` |
| **Device** | `auto` | `auto`, `cpu` или `cuda` |

Элементы этапов разделяют **SONARA**, **ML** и **CLASSIFIERS**. **FULL** запускает упорядоченный
конвейер. При запуске SONARA уже выбрана и всегда рассчитывает только Core; флажков результатов нет.
В выбор ML входят только MAEST, MERT, MuQ и CLAP; SONARA и
CLASSIFIERS остаются отдельными этапами. При первом запуске SONARA в каталоге без состояния SONARA
кнопка **Analyze** сразу запускает расчёт Core. Интерфейс также показывает очередь
и ход выполнения, ошибки отдельных файлов, причины блокировки, отмену и сброс из типизированных
ответов задач.

## Вкладки поиска

Основной список вкладок: **LAB**, **SONARA**, **MERT**, **MUQ**, **CLAP** и **CLASS**.
Клавиши `ArrowLeft` и `ArrowRight` переходят между вкладками, а `Home` и `End` — к первой и
последней.

MERT и MUQ используют общий интерфейс поиска по референсным трекам. Оба принимают лимит
`1..500` и выбранные референсные треки. Вкладка без актуальных эмбеддингов отключается с пояснением
для конкретного источника. Ошибка запроса остаётся видимой на вкладке и не подменяется пустым
успешным результатом.

## CLASS, LAB и Rhythm Lab

Вкладка **CLASS** фильтрует фонотеку по сохранённым оценкам классификаторов. Действие для отдельного
профиля сбрасывает и повторно рассчитывает только его `classifier_key`; аудио при этом не
декодируется. В основной панели анализа также доступны отдельный этап **CLASSIFIERS** и
упорядоченный конвейер **FULL**.

Вкладка **LAB** сравнивает референсный трек по CLAP, MERT, MuQ, MAEST и SONARA. Для недоступной модели
показывается отдельная причина. Запись вердикта содержит `catalog_uuid`, `track_uuid` и
`content_generation`, а действие MuQ отправляет `model="muq"`.

Кнопка Rhythm Lab в верхней панели вызывает `/api/rhythm-lab/launch` и открывает возвращённый
локальный адрес. Текущий сет можно сохранить как коллекцию для проверки в Lab. Отдельный Rhythm Lab
показывает состояния current, missing или stale для SONARA, MERT, MAEST, CLAP и MuQ; размеры страниц
равны `50`, `100`, `200` и `500`. Селектор **Training recipe** поддерживает MuQ и явные сочетания
источников. Старый рецепт `combined` по-прежнему означает `sonara+mert+maest`.

## Audio Dedup

Диалог Audio Dedup содержит флажки источников `mert`, `maest`, `muq` и audio-to-audio `clap`.
Он показывает исходные веса `0.43`, `0.32`, `0.12` и `0.04`, поддерживает **Custom raw weights** и
предлагает действия **Reset defaults** и **Pre-MuQ legacy**. Старый профиль выбирает `mert`,
`maest` и `clap` с исходными весами `0.43`, `0.32` и `0.04`.

По умолчанию создаётся только отчёт. Режим применения по-прежнему требует точную фразу
`APPLY DELETE`. Одних свидетельств MuQ или CLAP никогда не достаточно для удаления.
